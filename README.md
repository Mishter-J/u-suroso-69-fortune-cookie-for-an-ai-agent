Write one funny fortune cookie line for an AI agent. A judge model picks the funnier, more original line. Free to enter, and one line is the whole job. Built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` — one line, 81 characters.
